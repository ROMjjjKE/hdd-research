# HDD Research Group — hdd-research

Сайт центра восстановления информации (ИП Марченко Сергей Юрьевич), Гомель, ул. Кирова 55, оф. 312.

Стек: React 19 + Vite + TypeScript, GSAP + ScrollTrigger (только пин-сцена), Lenis.
Сборка статическая, деплой на GitHub Pages через Actions.

## Запуск

    npm install
    npm run dev      # локальная разработка
    npm run build    # сборка в dist/

## Структура

- `src/components/Gap.tsx` — пин-сцена «зазор 2 нм»: на десктопе скролл разводит волосок головки и
  поверхность пластины, открывает четыре подписи; на мобильном и при reduced-motion сцена статична.
- `src/components/Hero.tsx` — пластина в пятне света, 12 делений, вращение 90 с через CSS.
- `src/components/Media.tsx` — пять типов носителей.
- `src/components/Lab.tsx`, `Direct.tsx`, `Flow.tsx`, `Faq.tsx` — лаборатория в числах, «конечный
  исполнитель», порядок работы, вопросы.
- `src/styles/global.css` — токены и все блоки; `fonts.css` — @font-face с метрическими фолбэками.

## Шрифты

JetBrains Mono 400/700 (дисплей и служебные подписи), Inter 400/500 (текст). Оба с кириллицей,
файлы подрезаны по символам страницы pyftsubset, метрики фолбэков подобраны через canvas-замер
(size-adjust 100% и 105.7%), из-за этого CLS = 0.

## Что не выдумано

Все числа на сайте — из брифа заказчика: 20+ лет, тысячи восстановлений, 2 нм, ~120 км/ч, шесть
молекул азота, съёмник блока головок около 500 €. Цен, сроков, гарантий и «бесплатной диагностики»
на сайте нет, потому что заказчик их не называл.

## Изображений нет

Ни фотографий, ни SVG: пластина, пятно света и зазор собраны на CSS. Фон с зерном — одна png 64×64.

## Проверка

Lighthouse mobile: performance 96–97, accessibility 100, best practices 100, SEO 100,
LCP 2.1–2.2 с, CLS 0, TBT 0–180 мс. Проверены ширины 320–1680 без горизонтального переполнения.
